```text

  ↓
遇到失败
  ↓

  ↓

  ↓
重新运行实验
  ↓

```

# Stage 1：Harness Engineering

## 核心问题

> 给模型提供一个什么样的工作环境，它才能完成任务？

裸模型的问题：

```
LLM
 |
 |
任务

```

它不知道：

- 外部信息在哪里
- 工具怎么调用
- 文件怎么保存
- 权限是否允许
- 状态如何恢复

---

最终形成：

> **Agent-100-Days 提供知识地图，Agent Engineering Simulator 提供失败驱动实验。**

三个核心教学章节：

1. **Harness Engineering：让 Agent 能工作**
2. **Loop Engineering：让 Agent 可靠完成**
3. **Graph Engineering：让 Agent 支撑复杂系统**

这会比传统 Agent 教程更接近真实 Agent 工程实践。
